# Challenge set

원본 문서의 challenge 영역을 **정답을 먼저 정하고 대화를 생성**(by-construction)해 만든다.
자연 세트와 섞지 않는다 — 희소 감정과 경계 사례를 의도적으로 몰아넣은 세트라 실제 분포가 아니다.

## ⚠️ 골드는 사람 검수가 필요하다

여기 있는 골드는 **아직 검수 전**이다. by-construction 이라 설계 의도가 곧 라벨이지만, 생성 결과가
의도와 어긋나는 경우가 나오므로 사람이 한 번 읽어야 한다(계획 §6.2).

## boundary — 화남·답답·막막 (20세션)

| 영역 | 세션 | 정답 |
|---|---|---|
| 화남 | b01~b05 | angry — 부당함, 대상이 있음 |
| 답답 | b06~b10 | frustrated — 막힘, 소통 불능 |
| 막막 | b11~b14 | stuck — 방향 없음 |
| 복합 | b15~b17 | frustrated + angry 둘 다 |
| 부정 표현 | b18~b20 | 사용자가 부정한 감정은 담지 않는다 |

### 알려진 한계 — 지금 세트는 쉽다

감정 단어가 발화에 **그대로** 나온다("답답했어요", "화가 났어요"). 모델은 문자 그대로 매핑만 하면
되므로 zero-shot 도 감정 Macro F1 0.98 이 나왔다.

**진짜 경계 혼동은 감정 단어가 없을 때** 생긴다("몇 번을 말해도 그대로였어요" 만 있고 감정어가 없는
경우). 다음 판에서 **상황만 주고 감정어를 빼는 케이스**를 넣어야 변별력이 생긴다.

## 사용

```bash
# 예측을 뽑은 뒤
```
