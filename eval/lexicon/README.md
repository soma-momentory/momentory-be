# 감정 어휘 사전 (초안)

정본 대표 11종 · 세부 55개 기준. 원본은 [`emotion_lexicon.json`](emotion_lexicon.json) — 이 문서는 그걸 사람이 검토하기 쉽게 펼친 것이다.

## 한 파일, 두 용도

| 용도 | 방식 | 묻는 것 |
|---|---|---|
| **명시/간접 분기 · 학습 후보 추출** | 글자 일치(정규식) | 감정이 *이름으로* 드러났나? |
| **기타창 정규화** ("개빡침" → 분노) | 기준 단어(`ex`)와 임베딩 유사도 | 이 표현이 11종 중 뭔가? |

분기에 임베딩을 쓰지 않는 이유: 명시와 간접의 차이는 뜻이 아니라 겉모습이다. 임베딩은 뜻을 보므로 "병원에서 날 무시해"(간접)도 분노와 가깝게 나와 명시로 잘못 분류한다.

기타창에서 사용자가 확인한 새 표현은 이 사전에 추가한다 — 쓸수록 분기 쪽도 실사용 말투를 따라간다.

## 층위

| 층위 | 뜻 | 분기에서 |
|---|---|---|
| `name` | 대표·세부 감정 단어와 그 활용형 | **명시** |
| `colloquial` | 구어·신조어 — 감정을 이름으로 말한 것 | **명시** |
| `ambiguous` | 감정을 말했지만 11종 중 어디인지 문맥이 필요 — 분기에선 명시, 기타창에선 사람 확인 | **명시** |
| `out_of_scope` | 감정을 말했지만 11종 밖(질투·혐오) — 분기에선 명시, 기타창에선 체계 밖 | **명시** |
| `evaluative` | 상태·평가어 · 신체 반응 · 행동·인지 서술 — 감정을 이름으로 말하진 않음(간접) | 간접 |
| `weak` | 자주 걸리지만 감정 표현이 아닌 경우가 많음(실측 근거) — 명시로 치지 않음 | 간접 |

**부정('화난 건 아니고') · 타인('친구가 화났대') · 인용('서운하다는 말')은 사전이 못 가른다.** 학습 후보 추출에서는 그냥 명시로 빠져도 손해가 작지만(후보가 조금 줄 뿐), 서비스 감지기로 쓸 때는 규칙을 붙여야 한다(정본 §5.1).

## 애매 — 감정은 말했지만 어느 감정인지 문맥 필요

분기에선 명시로 친다. 기타창에선 후보를 보여주고 사용자가 고르게 한다.

| 표현 | 후보 | 메모 |
|---|---|---|
| 현타 왔어 | 실망 / 부끄러움 | 현자타임 — 허탈인지 자괴인지 문맥 필요 |
| 어이없었어 | 혼란 / 분노 | 황당인지 분노인지 |
| 빈정 상했어 | 실망 / 분노 | 말 한마디에 서운한지 화난지 |
| 자괴감 들어 | 부끄러움 / 미안함 | 수치심(시선)인지 자책감(행위)인지 — 부끄러움–미안함 경계 |
| 울컥했어 | 슬픔 / 분노 | 치미는 게 슬픔인지 화인지 |
| 짠했어 | 슬픔 / 애정 | 안쓰러움 — 슬픔인지 애틋함인지 |
| 싱숭생숭해 | 혼란 / 기쁨 | 심란함인지 설렘인지 |
| 마음이 상했어 | 실망 / 슬픔 | 서운함인지 속상함인지 |
| 절망스러웠어 | 실망 / 슬픔 | 좌절감(실망)인지 상실·비통(슬픔)인지 — 절망스럽다 38 |

## 평가어 — 기본값 **간접**

정본 §6 기준은 "자신의 감정을 *감정 단어로* 직접 표현"이다. 아래는 감정을 이름으로 말하지 않으므로 간접으로 둔다. "너무 힘들어"만으로는 슬픔·불안·실망 중 무엇인지 판단이 필요해, 자체 모델이 기여할 자리이기도 하다. **명시로 바꾸려면 이 층위를 `explicit_tiers` 에 넣으면 된다** — 그러면 간접 후보가 크게 준다.

## 약한 신호 — 걸리지만 감정 표현이 아닌 경우가 많음

| 예 | 근거 |
|---|---|
| 여자친구를 사랑하지만 부담돼 | 표적 수집에서 0/26 이 애정 — 관계 서술·타인 감정이 대부분 |
| 맛있는 걸 좋아해서 | 표적 수집 1/11 — 취향 서술이 대부분 |
| 해외여행을 가보고 싶어 | 그리움(엄마가 보고 싶어)과 시도(가 보고 싶어)를 글자로 못 가른다 |
| 소중한 시간 | 대상이 사람이 아닌 경우가 많다 |
| 교통이 편해 | 편리함과 편안함을 못 가른다 — '마음이 편'만 평온으로 |
| 정신없이 바빴어 | 바쁨 서술이 대부분 |
| 에휴 | 감탄사 — 감정 방향을 모른다 |
| 책임감을 느끼고 | 감정 범주가 아니다 — 검토 후 제외(책임감 24 · 신뢰감 16) |

## 점검

```bash
python3 check_lexicon.py                                   # 예문 시험
python3 check_lexicon.py --aihub "…/018.감성대화"            # + AI Hub 커버리지 · 놓친 단어 후보
```

2026-10-02 결과: 예문 24/24 통과(부정·타인·인용 3건은 규칙 몫). AI Hub 58,268건 중 **명시 65.9% · 간접 후보 34.1%(19,885건)** — 평가어만 15.4% · 약한 신호만 1.3% · 신호 없음 17.5%.

놓친 단어 후보 점검으로 절망·증오·환멸·회의감·소외감·고립감·감격·염려·유대감을 추가했다. 남은 후보는 빈도 5 이하(패배감·박탈감·곤혹·한탄·유감)이거나 일부러 간접으로 둔 평가어다.
