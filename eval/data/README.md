# 평가용 실제 데이터 (커밋하지 않음)

이 디렉터리의 내용은 **`README.md` 를 빼고 전부 gitignore 된다.**

## 왜

여기 들어오는 것은 세 사람이 쓴 **실제 회고 대화와 그 골드 라벨**이다. 개인적인 이야기이고,
커밋은 로깅보다 더 영구적이다(`AGENTS.md` 의 개인 일기 내용 취급 조항).

합성 데이터인 `eval/challenge/` 와 `eval/sample/` 은 개인정보가 없어 커밋한다. 갈리는 기준은
"사람이 자기 이야기로 쓴 것인가"다.

## 여기 두는 것

```
eval/data/
├── sessions.jsonl              psql 로 뽑은 state_json 원본
├── conversations.txt           dump.py 가 만든 대화 (프로브 형식)
├── gold.json                   labeler.html 로 단 골드
└── pred-<변형>.json            프로브 러너가 뽑은 예측
```

## 백업

리포가 안 지켜 주므로 **직접 챙겨야 한다.** 라벨링은 수 시간짜리 작업이라 날리면 복구가 안 된다.
`labeler.html` 이 localStorage 에 자동저장하지만 브라우저 데이터를 지우면 함께 사라지니,
작업 중에도 「JSON 내보내기」를 눌러 이 디렉터리에 파일로 남길 것.

## 동의

대화를 제공한 사람에게 **연구 목적 사용 동의**를 받은 뒤 수집한다. 라벨링하려면 원문을 전부
읽어야 한다.
