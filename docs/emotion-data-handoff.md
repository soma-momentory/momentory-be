## 1. 목표 (한 줄)

공개 가중치 생성형 모델(Qwen3-8B 등, LoRA/QLoRA)을 SFT해서, 사건별로 **감정 · 강도(1/2/3/판단 어려움) · 근거 발화 · 판단 보류**를 모멘토리 감정 체계로 출력하게 만든다.

같은 평가셋에서 세 방식을 비교한다.
- ① 기존 LLM 프롬프팅
- ② SFT
- ③ KoBERT

**분담 방향은 확정됐다.**
- 감정 단어가 겉으로 드러나는 *명시* 사례는 기존 LLM이나 사전·규칙이 맡는다.
- 자체 모델은 *간접·복합* 사례를 맡는다.
