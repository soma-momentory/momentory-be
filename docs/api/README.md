# 알림함 API

홈 v2 P5의 서버 알림함은 `GET /api/v1/notifications`, `GET /api/v1/notifications/unread`,
`PATCH /api/v1/notifications/{id}/read`, `POST /api/v1/notifications/read`를 제공한다.
인증된 사용자에게만 응답하며 로컬 회고·낮 기록 알림은 포함하지 않는다.

일반 공지(`NOTICE`, `NEWS` 및 이후 추가할 일반 유형)는 가입 시각 이후 발행분만 보인다.
발행 90일이 지났거나 설정된 `expires_at`이 지났으면 목록과 읽지 않음 판정에서 제외한다.
중요 공지(`CRITICAL_NOTICE`)는 필수 만료 시각 전까지 보이며, 가입 전 발행분은
`readAt`을 가입 시각으로 돌려주고 읽지 않은 알림으로 세지 않는다.
`audience`는 현재 `ALL`과 `USER`를 지원한다.

목록의 `size` 기본값은 20, 최대 50이며 최신 발행 시각과 ID 순서로 정렬한다.
`nextCursor`는 서버가 발급한 불투명 문자열이다. 클라이언트는 해석하지 않고 다음 요청에 전달한다.
읽음은 사용자별로 저장되어 기기 사이에 공유된다. 단건 읽음은 대상이 보이지 않거나 없으면
`404 NOTIFICATION_NOT_FOUND`, 일괄 읽음은 보이지 않는 ID를 건너뛴다.
두 읽음 API 모두 멱등이며 `204` 본문이 없다.

90일과 `expires_at`은 **목록 노출 기한**이다. 공지 행을 자동 삭제하는 작업은 현재 없으며,
물리적 보존 기간은 운영 정책이 정해진 뒤 별도로 도입한다. 사용자가 탈퇴하면 그 사용자의
읽음 기록과 `USER` 대상 공지가 외래키 연쇄 삭제로 같은 트랜잭션에서 정리된다.
공지 본문에는 개인 정보를 넣지 않는다.
